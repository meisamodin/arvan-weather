# اروان ودر — یادداشت‌های توسعه

## ساختار
- `index.html` — کل اپ (HTML + CSS + JS، بدون کتابخانه خارجی)
- `sw.js` — service worker (کش پوسته اپ برای حالت آفلاین، اعلان‌ها). با هر انتشار مقدار `V` را بالا ببرید.
- `manifest.webmanifest`, `icons/` — PWA و آیکن‌ها (معمولی + maskable)
- `privacy.html` — سیاست حریم خصوصی (لازم برای استورها)
- `dev/tests/smoke.py` — تست Playwright با داده ساختگی (بدون اینترنت): `python3 dev/tests/smoke.py out/`

## نسخه فعلی: 1.3.0 (با هر انتشار VERSION در index.html و V در sw.js بالا برود)

## tools.html
نسخه‌ای از index.html ماه قاسی (meisamodin/mah-ghasi) با این تغییرات: کلید ذخیره‌سازی `aw_tools` (جدا از ماه قاسی، چون هر دو روی یک دامنه‌اند)، فقط ابزارهای فهرست `AWT` (بدون قاعدگی/بارداری/نوزاد)، تب ابزار اجباری، هدر با دکمه بازگشت، رنگ آبی، تم از پارامتر `?th=dark|light`. برای به‌روزرسانی ابزارها، همین وصله‌ها را دوباره روی نسخه جدید ماه قاسی اعمال کنید.

## تم‌ها
`S.theme`: dyn (پویا بر اساس هوا) | dark | oled | light | sys — `applyTheme()`؛ اندازه متن `S.fs` با zoom روی تب‌ها (به‌جز نقشه و رادار).

## تب‌ها (ترتیب کارت‌ها بر اساس اهمیت)
1. اکنون: هشدارها → وضعیت فعلی + خلاصه (با مقایسه دیروز) + اشتراک → بارش ۲ ساعت آینده (minutely_15) → ساعتی ۲۴h → ۱۰ روزه → جزئیات → شاخص‌های روزانه → خورشید و ماه متحرک (ساعت طلایی/آبی، فاز ماه) → کیفیت هوا
2. پیش‌بینی: نمودار ساعتی (۴۸ ساعت / ۱۰ روز؛ دما، بارش، باد، رطوبت، UV، فشار) → جزئیات روزانه
3. کیفیت هوا: شاخص US/EU + توصیه سلامت → آلاینده‌ها (PM2.5، PM10، گرد و غبار، O3، NO2، SO2، CO) → پیش‌بینی ۷۲ ساعته → راهنما
3. رادار: بارش سراسری ایران (شبکه ۰٫۷۵ درجه minutely_15) | رادارهای کشور (RainViewer، ۹ ایستگاه IRIMO) | ماهواره ناسا IMERG (GIBS WMS، ~۷ ساعت تأخیر)
4. نقشه: باد متحرک + ۹ سطح ارتفاع + ۴۸ ساعت؛ لایه‌ها: باد، دما، بارش، گرد و غبار (air-quality API)، ابر، تندباد، زلزله (USGS)، فشار، رطوبت، برف
5. مدل‌ها: انتخاب مدل → اجماع و درجه اطمینان → نمودار مقایسه ۷ روزه → جدول → مدل‌های بدون داده → توضیحات

## منابع داده
- Open-Meteo: forecast, air-quality, geocoding (رایگان، بدون کلید؛ استفاده غیرتجاری رایگان، برای استفاده تجاری اشتراک لازم است)
- RainViewer: فقط رادار ۲ ساعت گذشته، بزرگ‌نمایی حداکثر ۷، طرح رنگ Universal Blue (از ۱ ژانویه ۲۰۲۶ ماهواره و nowcast حذف شد؛ فقط برای استفاده شخصی/آموزشی)
- کاشی نقشه: CARTO dark_all
- نام محل از GPS: BigDataCloud (reverse-geocode-client)

## مدل‌ها
هر مدل جدا درخواست می‌شود تا خطای یک مدل بقیه را خراب نکند. مدل منطقه‌ای خارج از محدوده = مقادیر null → «خارج از محدوده».
فهرست در آرایه `MODELS` داخل index.html.

## نکات
- همه داده‌ها و تنظیمات در localStorage با پیشوند `aw.`
- کش داده هر شهر ۱۰ دقیقه؛ مدل‌ها ۳۰ دقیقه
- هشدارها از پیش‌بینی ۷۲ ساعت + کیفیت هوا محاسبه می‌شوند (تابع `alerts()`)
